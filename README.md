# Market Data Analytics Dashboard

**Real-time HKEX market data: OHLCV, SMA/EMA, gainers/losers, technical signals.**  
*Targeting junior Java roles at HK investment banks.*

## ✨ Features
- OHLCV data storage & time-series queries
- Technical indicators: SMA(20), EMA(12)
- Top gainers/losers by volume/price
- REST APIs + caching layer
- PostgreSQL time-series DB

## 🛠 Tech Stack
Java 17+ - Spring Boot 3.2+ - PostgreSQL - Maven - GitHub Actions CI


## 🚀 Quick Start
```bash
git clone https://github.com/YOUR_USERNAME/market-dashboard.git
cd market-dashboard
mvn clean install
mvn spring-boot:run

Live Data: http://localhost:8080/api/market/hsi
